# 김비서 서버 설치 (운영자가 Supabase 대시보드에서 1회)

프로젝트: `bqyepkbajnnguhhcixfv` (조직 kimbiseo, Free)

1. **SQL Editor** → `01_kbs_items.sql` 전체 붙여넣기 → Run → 마지막 결과 `kbs_items | true` 1줄 확인.
2. **Authentication → Users → Add user → Create new user**: 본인 이메일·비밀번호, **Auto Confirm User 체크**.
3. **Authentication → Sign In / Providers**(또는 Settings): **Allow new users to sign up 끄기** (본인 외 가입 차단).
4. **Anthropic 콘솔**(console.anthropic.com) → API Keys → 새 키.
   Supabase **Edge Functions → Secrets**: `ANTHROPIC_API_KEY` = 그 키, `OWNER_EMAIL` = 2번 이메일.
5. **Edge Functions → Deploy a new function → Via Editor**: 이름 `kbs-ai`, `functions/kbs-ai/index.ts` 내용 붙여넣기 → Deploy.
   - 앱에서 Claude가 안 되고 함수 로그에 `Invalid JWT`/401이 보이면: 함수 설정의 **Verify JWT** 끄기 (함수가 직접 로그인 확인함).
6. 앱 → ⚙ 설정 → 로그인.

확인: 입력칸에 "사귄 날 2024년 3월 1일 등록해줘" → 미리보기 태그가 **D-day**로 나오면 Claude 해석 작동(규칙 해석은 '일정'으로 나옴).

## 아침 알림 (v5)
7. **SQL Editor** → `02_kbs_push.sql` Run → `kbs_push | true`.
8. **Edge Functions → Secrets**: `VAPID_PUBLIC_KEY`·`VAPID_PRIVATE_KEY`·`CRON_SECRET` (값은 채팅으로 받은 비밀값 파일 — 저장소에 없음).
9. **Edge Functions → Deploy a new function → Via Editor**: 이름 `kbs-brief`, `functions/kbs-brief/index.ts` 붙여넣기 → Deploy → 함수 설정에서 **Verify JWT 끄기**(크론 호출엔 로그인 토큰이 없음 — 함수가 CRON_SECRET·로그인 토큰을 직접 확인).
10. **SQL Editor** → CRON_SECRET이 채워진 `03_kbs_brief_cron.sql` 실행본 Run → `kbs-brief-hourly | 0 * * * * | true`.
11. 앱(폰, 홈 화면 설치본) → ⚙ 설정 → 아침 알림 → 시각 고르고 [알림 켜기] → [테스트 알림].
